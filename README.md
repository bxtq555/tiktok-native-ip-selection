## “独享原生IP”四个字，拆开是四件事

卖家页面常把这几个词混着用，实际是四个独立属性，缺一个效果就打折。

**独享**指这台机器的 IPv4 只有你在用。共享 IP 的麻烦在于你无法知道同 IP 上还有谁在做什么，一旦有人触发风控，整段 IP 上的账号一起受影响。某家 TikTok 加速服务商的官方案例里，一家 100 名主播的 MCN 用普通网络、多账号共用出口 IP，三个月封掉 4 个月打赏过万美元的账号（商家自述，未经第三方验证）。这类案例的具体数字不必全信，逻辑成立：平台判关联主要看网络环境。

**原生**指 IP 的 whois 注册归属地和机房实际所在国一致。机房在洛杉矶、IP 库标美国，平台就按美国用户给你分流量。用香港 IP 跑美区账号，地理位置矛盾，基础推流就不一样。

**家宽（住宅）**指这段 IP 属于当地 ISP 的家庭宽带地址段，在风控眼里更接近真实用户。原生和家宽是两件事，WePC 的列表里两个都卖，而且分别标注：英国的 AUD$10.90 那档写的是“原生 IPv4”，AUD$14.90 那档写的是“原生家宽 IPv4”，差 4 澳元，差别就在这里。

**双 ISP** 指这段地址由两个上游运营商承载，比单 ISP 更像一个真实的家庭网络环境。WePC 的美国洛杉矶、纽约、韩国、日本几档都标了双 ISP。

反过来，机房 IP（页面里写作 IDC）就是数据中心地址段，便宜，也最容易被识别。WePC 自己就有一档“新加坡原生 IDC IPv4”，AUD$16.90，标注写得很直白。

## 带宽和流量的三个口径，别拿端口速率当推流能力

同一条直播，你在不同文章里会看到三个数字：6–10Mbps、100Mbps、5M。它们说的不是一回事。

**推流码率**：TikTok 1080P 直播推流大致需要稳定 6–10Mbps 上行，4K 更高。这是你实际持续占用的带宽。

**端口带宽**：WePC 标的 50 / 100 / 200Mbps 属于这一类，是这台机器网卡的理论上限，不代表你在晚高峰能稳定跑满。

**保障 / 容量口径**：有商家按“5M 带宽支持 1 台手机直播 + 1 台手机运营、10M 支持 3 台直播 + 2 台运营”来折算，也有商家写“单人直播 100Mbps 起步是稳妥线”。前者是专线容量估算，后者偏保守的销售口径，两者都不能直接和推流码率比大小。

落到 WePC 的套餐上，印尼那档 50Mbps、韩国那档 100Mbps，按推流码率算余量很大，真正的瓶颈通常在国内到入口这一段回程，以及本地网络。S8 的 5M/10M 那种算法对应的是点对点专线的保障带宽，不适合拿来反推 WePC 的端口参数。

流量这边要看“双向”两个字。WePC 全系按双向计费，上下行都算进套餐总量。按 1080P、6Mbps 上行估算，一小时纯推流约消耗 2.7GB，2TB 双向大约能撑 700 多小时纯直播；如果只是发视频、养号，一个月几 GB 都用不到。做日播 6 小时的团队，2TB 需要按月算一遍账。

## 常见问题

**原生 IP 和家宽 IP 差在哪？**

原生说的是 whois 归属地和机房所在国一致，家宽说的是这段地址属于当地 ISP 的家庭宽带段。原生 IP 能过地区判断，家宽 IP 在风控眼里更像真人。WePC 两档都卖，价格差 4 澳元左右，做直播建议直接买家宽。

**一个 IP 能登几个号？**

一个。多账号共用出口 IP 是账号被判关联最常见的原因，WePC 全系一机一独立静态 IPv4，就是为了让每个账号有自己的环境。

**IP 被封了怎么办？**

WePC 的公开列表和条款里没写明确的换 IP 政策，下单前问客服确认，比事后扯皮省事。行业里其他商家的做法可作参考：有商家承诺 48 小时内 IP 被封免费更换一次，超过 48 小时每次 30–50 元。这是别家的政策，不能安到 WePC 头上。

**手机直播和电脑直播，带宽要求差多少？**

手机单路 1080P 推流按 6–10Mbps 上行算就够，OBS 多机位、高码率、加推流备份会成倍往上走。WePC 100Mbps 和 200Mbps 的端口对单路手机直播余量很大，真正的变量是回程稳不稳、要不要中转。

**做美区，必须买洛杉矶吗？**

出口落美国是前提，具体城市影响延迟和线路优化。WePC 的洛杉矶 4837 / 9929 两档标了“无需中转”，纽约那档也标了 4837 优化，比买其他州再自己搭中转省事。
